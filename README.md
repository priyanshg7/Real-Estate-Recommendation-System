# Real Estate Recommendation System

[![Deployed on Vercel](https://img.shields.io/badge/Vercel-Live%20Demo-blue?style=flat&logo=vercel)](https://real-estate-recommendation-system.vercel.app)

A comprehensive machine learning and data analytics project for Gurgaon real estate properties, featuring end-to-end data cleaning, preprocessing, feature engineering, outlier detection, missing value imputation, exploratory data analysis, and an interactive web dashboard.

🌐 **Live Web Application**: [https://real-estate-recommendation-system.vercel.app](https://real-estate-recommendation-system.vercel.app)

## 📁 Project Structure

- `1_data_preprocessing_flat.ipynb`: Data cleaning and preprocessing for flat listings.
- `2_data_preprocessing_house.ipynb`: Data cleaning and preprocessing for house listings.
- `3_merging_flat_and_house.ipynb`: Merging cleaned datasets into a unified format.
- `4_data_preprocessing-combined_dataset.ipynb`: Additional processing on the combined property data.
- `5_feature_engineering.ipynb`: Feature extraction, transformation, and engineering.
- `6_Outliers_treatment_missing_value_imputation.ipynb`: Outlier detection and missing value imputation pipelines.
- `7_EDA_Univariate_Analysis.ipynb`: Univariate exploratory data analysis.
- `8_EDA_Multivariate_Analysis.ipynb`: Multivariate exploratory data analysis and correlation studies.
- `raw_Data/`: Raw scraped property data.
- `data_first_cleaning/`: Intermediate cleaned datasets.
- Processed CSV files: `gurgaon_properties_cleaned_v2.csv`, `gurgaon_properties_cleaned_v3.csv`, `gurgaon_properties_final.csv`, `gurgaon_properties_prefinal.csv`, `OT_MVI.csv`, `appartments.csv`.
